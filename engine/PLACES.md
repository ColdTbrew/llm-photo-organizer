# Place reference data

`places.tsv` contains public place names and coordinates derived on 2026-09-26 from the GeoNames `cities15000.zip` and `KR.zip` gazetteer extracts. It includes entries with Korean alternate names, plus Korean administrative centers and populated cities. It contains no user photos, GPS records, or personal settings.

Source: https://download.geonames.org/export/dump/

GeoNames data is licensed under [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/). GeoNames says the data is provided without a guarantee of accuracy. The app treats the nearest name as a hint, not an administrative boundary lookup.
